# Подбор эмодзи для ИИ и сохранение стиля приложения

ИИ сначала определяет назначение символа, получает небольшой список реальных
кандидатов, проверяет превью и выбирает основной пак. Новые экраны используют
сохранённые роли, а не случайный новый результат поиска. Индекс охватывает весь
каталог; идентификаторы всегда строки.

## Поиск и выбор пака

```powershell
python tools/select_emoji.py search 'значок напоминания' --style minimal --limit 8
python tools/select_emoji.py search 'GitHub' --pack SocialEmojis
python tools/select_emoji.py search 'колокольчик без звука' --style minimal
python tools/select_emoji.py search 'уведомления' --animation static --color monochrome --repainting required
python tools/select_emoji.py styles
python tools/select_emoji.py palette --style minimal --roles settings search notification success download
```

Поиск использует проверенные названия и ключи, словарь русских/английских
синонимов и назначений. Он не выполняет новое распознавание изображения и не
обращается к платной модели. Сложную задачу ИИ разбивает на роли. Неизвестные
названия, прозрачные изображения, недоступные файлы, буквы, цифры и фрагменты
исключены из обычной рекомендации. Для их осознанного анализа существует
`--include-special`. Отсутствие результата требует уточнения запроса, а не
выдуманного ID. Действие отделяется от объекта: «удалить файл» требует значка
удаления; папка — контекст. «Колокольчик без звука» требует зачёркнутого значка,
«не разбитое сердце» исключает разбитые, «сердце без неона» исключает неоновый пак.
Корзина покупок и плетёная корзина не служат обозначением удаления.

Сначала прочитай `decision`: `matched` позволяет рассматривать кандидатов с
`recommended=true`; `needs_review` требует проверки слабого совпадения;
`needs_clarification` сообщает о нескольких назначениях/стилях или противоречивых
ограничениях; `no_match` означает отсутствие подходящего результата. `browse` —
обзор каталога. Разбей несколько ролей на отдельные запросы, разреши неоднозначность
по контексту приложения. `full` означает прямое свидетельство в названии/ключе для
каждого основного назначения, `partial` — для части, `category_only` — только
общую категорию. Это не вероятность правильности. Название пака не доказывает
назначение каждого элемента. Слабые совпадения не заполняют профиль автоматически.

Стилевые семейства помогают искать. Строгое единство достигается одним паком,
проверкой реальных форм и записью конкретных ID для каждой роли. Даже два
контурных пака могут различаться толщиной линии и заполнением. Адаптивность
Telegram (`adaptive`) не равна одноцветности (`monochrome`). Если в приложении
важна статичность, одноцветность или перекрашивание, используй `--animation`,
`--color` и `--repainting`: неизвестные метаданные не удовлетворяют строгому
ограничению. `animated=null` и `color_mode=unknown` у старых записей означают
отсутствие данных. Фильтры состояния основаны на проверенных названиях, поэтому
отсутствие признака `counter` ещё не доказывает, что на рисунке нет цифр. Проверь
само превью перед окончательным выбором.

## Профиль в создаваемом приложении

```powershell
python tools/select_emoji.py palette --style minimal --roles settings search notification success download --profile 'C:\path\my-app\emoji-style.json' --save
python tools/select_emoji.py palette --roles info calendar --profile 'C:\path\my-app\emoji-style.json' --save
python tools/select_emoji.py palette --style outline --pack ref_x3_collab --roles notification calendar --animation static --color monochrome --repainting required --profile 'C:\path\other-app\emoji-style.json' --save
python tools/select_emoji.py validate 'C:\path\my-app\emoji-style.json'
```

Первый запуск выбирает один пак с максимальным покрытием запрошенных ролей.
Следующий добавляет новые роли из того же пака, сохраняя предыдущие ID. Новый
каталог или порядок ранжирования не меняет принятые решения. Без `--save`
команда только возвращает результат. При отсутствии роли она указана в
`missing_roles`; автоматического смешивания паков нет. Уже записанный
`secondary_packs` разрешает заполнить пробел из этого источника после основного.

Профиль содержит `schema_version`, `style`, `primary_pack`, `secondary_packs`,
`roles` и `catalog_version`; при ограничениях добавляется `constraints`.
Последующие вызовы наследуют ограничения. Если более строгое требование
несовместимо с сохранённым ID, команда возвращает ошибку и не переписывает файл.
В каждой роли сохраняются строковый `id`, `key`,
`name`, `pack` и настоящий `html_fallback`. Второй пак добавляют осознанно
после визуальной проверки; валидатор требует совместимого семейства. Для
изменения общего стиля используй новый профиль либо явно пересмотри существующий
набор. Хранить профиль следует в проекте приложения и использовать единый
помощник для его отображения.

## Именованные роли и состояния

Одно назначение может иметь несколько состояний. Назови роли так, как они
используются в приложении, и передай описание через повторяемый `--role-query`:

```powershell
python tools/select_emoji.py palette --style minimal --pack sfsymbols --roles notifications_on notifications_muted --role-query 'notifications_on=включить уведомления' --role-query 'notifications_muted=колокольчик без звука' --profile 'C:\path\my-app\emoji-style.json' --save
python tools/select_emoji.py search 'отключить уведомления' --profile 'C:\path\my-app\emoji-style.json'
python tools/select_emoji.py palette --roles notifications_muted search --profile 'C:\path\my-app\emoji-style.json' --save
```

`notifications_on` получит обычный колокольчик, `notifications_muted` —
зачёркнутый из того же пака. Каждая роль хранит `query` рядом с `id`; повторять
описание при следующем вызове не требуется. Для открытого и закрытого доступа
используй отдельные роли с запросами «открытый замок» и «закрытый замок».
Валидатор обнаруживает подмену нормального значка выключенным и наоборот.
Старые профили с обычными ключами `notification`, `search` сохраняют совместимость.

После проверки формы, толщины линий и заполнения сохрани конкретный вариант:

```powershell
python tools/select_emoji.py search 'edit' --profile 'C:\path\my-app\emoji-style.json'
python tools/select_emoji.py palette --roles editor_button --role-query 'editor_button=edit' --bind 'editor_button=6025951481222403788' --profile 'C:\path\my-app\emoji-style.json' --save
```

Этот ID обозначает редактирование в круге из `sfsymbols`. `--bind` проверяет
назначение, состояние, ограничения и разрешённые паки. Если роль уже сохранена,
другой ID или другое описание возвращают ошибку без перезаписи. Для нового
состояния создай новую роль; изменение общего дизайна требует пересмотра профиля.
`unresolved_roles` указывает запрос и причину, если роль не удалось заполнить.

`search --profile` наследует стиль, паки и ограничения; `saved_roles` помечает
принятые ранее ID и ставит подходящий сохранённый вариант выше нового результата.
Второй пак участвует только после записи в `secondary_packs`. Поиск не изменяет
файл профиля. `profile_context.catalog_changed` сообщает, что каталог обновился;
само обновление каталога не меняет выбранные эмодзи.

## Составные изображения

```powershell
python tools/select_emoji.py compositions 'ПОЛЕЗНОЕ' --pack nexus_base
python tools/select_emoji.py compositions --pack nexus_base --limit 20
```

Результат содержит полный HTML и `emoji_ids` в исходном порядке с повторами.
Пропавшие части и сборки, требующие уточнения, исключаются. В профиль можно
добавить `composition_roles`, где значение роли содержит `key` сборки и полный
массив `emoji_ids`. Проверка обнаруживает изменение порядка и потерю повторов.

## В каталоге

Фильтр стиля сохраняется в этом браузере. «Сохранить стиль этого пака» закрепляет
также конкретный источник. Кнопка «Профиль сохранённого стиля» экспортирует его
даже при пустом поиске или переходе в другой раздел. Просмотр другого элемента
не заменяет сохранённый источник. Без закреплённого пака «Профиль стиля для ИИ»
копирует профиль текущего пака: передай его ИИ вместе с описанием приложения и сохрани как
`emoji-style.json` в его проекте. ИИ затем заполняет роли через команду `palette`.
Экспорт сам по себе не редактирует другое приложение.

Программный индекс публикуется в
[emoji-index.json](https://zulut30.github.io/premium-telegram-emoji/emoji-index.json).
Сайт и инструмент используют одну политику назначений и один набор метаданных.
Для сложного запроса сайт показывает причину неоднозначности. Контрольные
запросы и ожидаемые состояния сохранены в `tests/selection_cases.json`; тесты
сравнивают также планы поиска, решения и порядок кандидатов сайта и инструмента.

## Игровые боты

Разделяйте название игры и действие в интерфейсе. Для раздела Minecraft можно
использовать проверенную эмблему игры; для кнопки инвентаря нужен рюкзак, для
начала игры — воспроизведение. Слово «игры» не делает логотип издателя подходящим
для любого действия. «Шахматная прозрачность» описывает текстуру интерфейса,
а не настольную игру.

Поддерживаемые роли:

| Ключ | Назначение | Пример запроса |
| --- | --- | --- |
| `controller` | Игровой контроллер | геймпад |
| `board_game` | Настольные игры | игральные кости |
| `play` | Начало игры | начать игру |
| `inventory` | Инвентарь | инвентарь |
| `reward` | Награды | награды |
| `achievement` | Достижения | достижения |
| `leaderboard` | Таблица лидеров | рейтинг игроков |
| `tournament` | Турнир | турнир |
| `quest` | Задания | ежедневное задание |
| `health` | Здоровье персонажа | здоровье персонажа |
| `currency` | Игровая валюта | игровая валюта |
| `victory` | Победа | победа |
| `defeat` | Поражение | поражение |

Алиасы охватывают Minecraft/Майнкрафт, Hearthstone/Хартстоун, Dota/Дота,
Counter-Strike/CS2/CS:GO/КС2, Warcraft/World of Warcraft/WoW/Варкрафт,
Fortnite/Фортнайт, League of Legends/LoL/ЛОЛ и Overwatch/Овервотч.
Другие игры ищутся по проверенным названиям каталога; наличие алиаса не
гарантирует наличие каждого героя, предмета или версии игры.

```bash
python scripts/select_emoji.py search "Майнкрафт" --pack GameIcons
python scripts/select_emoji.py search "CS2" --pack GameIcons
python scripts/select_emoji.py search "начать игру" --pack sfsymbols
python scripts/select_emoji.py search "Minecraft инвентарь" --pack sfsymbols
python scripts/select_emoji.py palette --style minimal --pack sfsymbols --roles play inventory reward achievement leaderboard tournament quest health currency victory defeat settings --profile "/path/to/bot/emoji-style.json" --save
```

Палитра держит все обычные роли в одном паке. Игровые эмблемы выбирайте отдельной
палитрой с явным `--pack GameIcons --style brand`; если нужны обе группы в одном
приложении, явно разделите группы ролей и храните два профиля. Добавление пака
другого семейства в `secondary_packs` одного профиля не пройдёт проверку стиля.

Для нескольких игр ищите каждую эмблему отдельно. Запрос «Майнкрафт и Дота»
сообщает неоднозначность; «Майнкрафт без Доты» учитывает исключение целиком.
Название игры не превращается в счётчик или действие: `Counter-Strike` не
означает «значок с числом», а `PlayStation` — «начать игру».

Абстрактные роли используют понятные визуальные метафоры: кубок для турнира,
медаль для достижения, сердце для здоровья. Уточняйте специальную механику
приложения и просматривайте реальные изображения. Строгие требования к анимации,
цвету и адаптивности сохраняются; например, в sfsymbols рюкзак и сердце
анимированы, поэтому статичный вариант для этих ролей из этого пака не находится.
При обновлении ранее одобренный контроллер для «играть» или медаль для рейтинга
остаются закреплёнными; обновлённое ранжирование их не заменяет.
